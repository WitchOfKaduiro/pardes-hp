ロボティクス・AI導入を阻む3つの壁に挑む。Pardesの事業モデルと開発ロードマップをご紹介します。

Index

Business Challenges

3つの壁

  • 01/

    学習コストの壁

    大量の学習データと計算資源を必要とする従来型の深層学習は、多くの現場にとって導入コストが高すぎます。

  • 02/

    ハードウェアの壁

    GPUへの依存は高い消費電力とコストを招き、エッジデバイスやモバイルロボットへの搭載を難しくしています。

  • 03/

    知能の硬直化

    一度学習したモデルはその場の環境変化にリアルタイムで適応しにくく、現場ごとの再学習・再設計が必要になりがちです。

BiNetとは

  • 時間的累積・時間的平滑化

    入力される情報を時間軸上で蓄積・平滑化し、瞬間的なノイズに影響されにくい学習を行います。

  • 神経伝達物質の模倣

    生体内の神経伝達物質の働きを模したメカニズムにより、生物学的妥当性の高い情報処理を実現します。

  • 確率的収束による学習

    勾配計算に基づく誤差逆伝播法ではなく、確率的な収束過程によって学習を行います。詳しい技術比較は製品説明ページをご覧ください。

Developer Kit

BiNet SDK

ロボットベンチャー・研究機関向けの開発者キットです。既存の機体・研究環境にBiNetを組み込み、即時学習機能を検証できます。

主な特徴

  • 開発者向けAPI

    既存の機体・研究環境にBiNetを組み込み、独自のロボット制御ソフトウェアと接続できます。

  • 実証環境での検証

    研究機関・ロボットベンチャーが自社の実機で、即時学習の挙動を検証できます。

Production Module

BiNet Binary Module

量産・実運用フェーズの企業向け、特定基盤にロックされた推論実行エンジンです。本番環境での安定運用を前提とした、実行専用モジュールとして提供します。

主な特徴

  • 特定基盤向け推論エンジン

    量産機に搭載する特定のハードウェア基盤にロックされた、実行専用の推論モジュールです。

  • 量産運用を前提とした安定性

    本番環境での長期連続稼働を前提に設計されています。

Custom Integration

Custom Integration

特定業界向けの共同開発形式でのご提供です。個別の業界要件に合わせ、Pardesと共同でBiNetの適用を設計・開発します。

主な特徴

  • 個別要件への共同設計

    特定業界・特定用途の要件に合わせ、Pardesと共同でBiNetの適用範囲を設計します。

  • 業界特化の実装支援

    導入先の業務フローやハードウェア制約に合わせた実装を伴走支援します。

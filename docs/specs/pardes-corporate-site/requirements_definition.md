# 要件定義書

## 1. 文書概要
- 対象システム: Pardes Inc. コーポレートサイト（新規構築、7ページ構成）
- 文書種別: 要件定義書
- 版数: v1.3
- 最終更新日: 2026-07-21
- 位置づけ: `shared_understanding.md` の確認結果を前提とした、本サイトの機能要件・非機能要件の定義

## 2. 目的

AGI（汎用人工知能）開発企業 Pardes Inc. のコーポレートサイトを、HOME／事業紹介／会社概要／製品説明／採用情報／お知らせ／お問い合わせ の7ページ構成で新規構築するにあたり、各ページが持つべきコンテンツ要件・情報設計・導線と、サイト横断の非機能要件を定義する。

## 3. 対象範囲（スコープ）

### 3.1 本版対象
- 7ページのコンテンツ要件、情報階層、CTA、ページ間導線
- 全ページ共通のデザイン方針（配色・書体・レイアウト原則）
- お問い合わせフォームの機能要件と、個人情報保護・スパム対策に関する非機能要件
- 日本語版・英語版の2言語でのページ提供（`shared_understanding.md` CHK-SCOPE-01、2026-07-21ユーザー回答により確定）
- 検索エンジン・生成AIエンジン・LLMからの可視性を高めるための機能要件（AIO・SEO・GEO・LLMO対策、詳細は`aio_seo_geo_llmo_strategy.md`）

### 3.2 本版対象外
- データベース設計、ER図、インフラアーキテクチャ設計、RTM、実装タスク化（`shared_understanding.md` 決定事項 DEC-03）
- 独立したセキュリティ設計書（お問い合わせフォームの保護要件は本文書の非機能要件に内包する、DEC-04）
- 技術スタック・ホスティング環境の選定（CHK-IMPL-01）
- お知らせページの更新手段（CMS等）の具体設計（CHK-FLOW-02）
- 松尾工務店サイトのコンテンツ・コード・画像の流用（著作権上、対象外）

### 3.3 本版で未確定の事項
- サイト全体で最優先とするコンバージョンの明確化（CHK-GOAL-01、ISSUE-04、ユーザー未確認）
- 会社概要ページの所在地・設立日・資本金（`shared_understanding.md` 6.未確定事項）
- サイト公開時期・ローンチ目標日（ISSUE-01）
- お知らせページの更新運用体制
- 個人情報の保持期間・削除方針の具体値

## 4. 前提

`shared_understanding.md` の前提（PRE-01〜PRE-05）および決定事項（DEC-01〜DEC-04）を前提とする。特に、本サイトは事業計画書（`docs/Pardes_事業計画書 BIL_20260712.pdf`）に基づくが、同文書は投資家向け機密情報を含むため、本サイトへの掲載可否は個別に判断している（5章の各REQ参照）。

## 5. 用語定義

| 用語 | 定義 |
| --- | --- |
| BiNet（バイネット） | Pardes Inc.が開発する、誤差逆伝播法（BP）を使用しない生物学的妥当性の高いニューラルネットワーク技術 |
| BIL（BiNet Intelligence Licensing） | BiNetをNPU上で動作する知能モジュールとしてライセンス提供する事業モデルの名称 |
| BiNet SDK | BIL事業モデルの提供形態の一つ。ロボットベンチャー・研究機関向けの開発者向けキット |
| BiNet Binary Module | BIL事業モデルの提供形態の一つ。特定基盤にロックされた推論実行エンジン |
| Custom Integration | BIL事業モデルの提供形態の一つ。特定業界向けの共同開発形式による提供 |
| AGI（汎用人工知能） | 特定タスクに限定されない汎用的な知能を持つ人工知能。Pardes Inc.が掲げるビジョン |
| BP（誤差逆伝播法） | 既存の深層学習で広く使われる勾配計算による学習手法。BiNetはこれを使用しない設計を特徴とする |
| PoC | 概念実証。事業紹介ページ等で募集するパートナーシップの形態 |
| CTA | サイト訪問者に特定の行動（お問い合わせ送信等）を促すページ内の導線要素 |
| REQ-ID | 本文書内で機能要件・非機能要件を一意に識別する番号 |
| UC-ID | `UseCase_List.md` 内でユースケースを一意に識別する番号 |

- v1.0: 初版作成。事業計画書PDF（全13ページ、Vision抽出）、既存ティザーサイト（`pardes-hp.vercel.app`）の調査結果、参考サイト（松尾工務店）から抽出した構造原則に基づき、7ページ構成のコーポレートサイト要件を新規に定義した。

- v1.2: `aio_seo_geo_llmo_strategy.md` を新設し、AIO・SEO・GEO・LLMO対策の機能要件（REQ-SEO-01〜10）を9.9として追加した。
- v1.3: JSON-LD詳細、Google Search Console運用、robots.txtでのAIクローラー許可方針、sitemap.xmlのhreflang構成、OGP/Twitter Card/favicon整備を具体化し、REQ-SEO-11〜15を追加した。

## 8. 利用者と権限

### 8.1 利用者種別
- サイト訪問者（ロボット/AI開発企業の技術者・研究開発責任者を主対象とする一般訪問者）
- 採用候補者
- Pardes Inc. 運用担当者（お知らせ更新、お問い合わせ対応）

### 8.2 権限ロール
- 閲覧者: 全7ページの閲覧、お問い合わせフォームの送信が可能
- 運用担当者: コンテンツ更新権限を持つ（更新対象範囲・認可方式は未確定、CHK-FLOW-02）

### 8.3 権限制約
- 会員登録・ログイン機能は本版対象外のため、権限区分は「閲覧者」「運用担当者」の2種のみとする
- 運用担当者向けの操作画面・認可方式の詳細は本文書の対象外とする

## 10. 非機能要件

### 10.1 認証・認可
本サイトは一般公開ページであり、閲覧者向けの会員認証は行わない。お知らせ更新等の運用担当者操作における認可方式は未確定（CHK-FLOW-02）であり、後続の設計フェーズで定義する。

### 10.2 データ分離
テナント分離を要する構成ではないため対象外とする。

### 10.3 データ整合性
お問い合わせ送信データは、担当者への通知内容と保存内容が送信時点の入力内容と一致する状態を維持する。お知らせ本文の編集履歴保持の要否は未確定事項とする。

### 10.4 監査性・追跡性
お問い合わせ送信の送信日時と目的区分を記録する（REQ-CONTACT-05に対応）。ページ閲覧・CTAクリックの計測方法は未確定事項とする。

### 10.5 運用性
お知らせの更新手段・更新者・更新頻度は未確定事項とする（REQ-NEWS-04に対応）。公開後のコンテンツ修正の頻度・手順は本版の対象外とする。

### 10.6 セキュリティ
お問い合わせフォームの送信内容はHTTPSによる暗号化通信で送受信する。スパム対策を導入する（REQ-CONTACT-04）。個人情報の保持期間・削除方針の具体値は未確定事項とする。

### 10.7 性能・拡張性
全ページはスマートフォン・タブレット・デスクトップの各表示幅において、要素の重なり・はみ出しが発生しない状態で閲覧できる（REQ-DESIGN-06に対応）。将来の英語版追加（ISSUE-02）およびコンテンツ量増加への対応方針は未確定事項とする。

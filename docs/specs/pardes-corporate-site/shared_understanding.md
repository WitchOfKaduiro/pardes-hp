# 共通理解確認

## 1. 文書概要
- 対象システム: Pardes Inc. コーポレートサイト（新規構築、7ページ構成）
- 文書種別: 共通理解確認
- 版数: v1.2
- 最終更新日: 2026-07-21
- 位置づけ: 要件定義前の認識合わせ結果

## 2. 目的

AGI（汎用人工知能）開発企業 Pardes Inc. の新しいコーポレートサイトを構築するにあたり、既存資料（事業計画書、既存ティザーサイト、参考サイト調査結果）から判断できる事項と、ユーザー確認が必要な事項を分離し、要件定義書（`requirements_definition.md`）の前提とする。

## 3. 対象範囲

### 3.1 対象
- HOME、事業紹介、会社概要、製品説明、採用情報、お知らせ、お問い合わせ の7ページのコンテンツ要件・情報設計方針
- 各ページの目的、想定コンテンツ、情報階層、CTA、ページ間導線
- お問い合わせフォームに関する非機能要件（個人情報保護、送信先振り分け）
- 共通デザイン方針（既存資産のトーン統一、参考サイトからの構造原則の反映）
- 日本語版・英語版の2言語でのページ構築（CHK-SCOPE-01、2026-07-21ユーザー回答により確定）

### 3.2 対象外
- データベース設計、ER図、インフラアーキテクチャ設計、RTM、実装タスク化（本サイトは静的な情報発信＋問い合わせフォームが中核であり、永続データ・複雑インフラが薄いため今回は作成しない）
- 具体的な技術スタック・ホスティング環境の確定（後続の設計フェーズで決定）
- 松尾工務店サイトの文言・画像・コード（実装コードそのもの）の流用（同社の著作物であり対象外）。ただしレイアウト・配置・アニメーション仕様（構造原則・数値スケーリング手法・モーション仕様）は正として参照してよい（DEC-02改訂、2026-07-21ユーザー指示）

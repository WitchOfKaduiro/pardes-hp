# ユースケース一覧

## 1. 文書概要
- 対象システム: Pardes Inc. コーポレートサイト（新規構築、7ページ構成）
- 文書種別: ユースケース一覧
- 版数: v1.1
- 最終更新日: 2026-07-21
- 位置づけ: `requirements_definition.md` の各機能要件が参照する業務行動単位の一覧

## 2. 目的

サイト訪問者・運用担当者が行う業務上の行動を、画面単位ではなく行動単位で整理し、要件定義書の各REQ項目と対応づける。

## 3. 対象範囲

7ページ（HOME／事業紹介／会社概要／製品説明／採用情報／お知らせ／お問い合わせ）における閲覧行動、お問い合わせ送信行動、および付随する自動処理・例外処理を対象とする。認証を伴う会員機能・管理画面の詳細操作フローは対象外（お知らせ更新等の運用者操作は概要のみ記載し、詳細は本版対象外）。

## 4. 前提

`shared_understanding.md` の決定事項・未解決事項を前提とする。多言語対応はCHK-SCOPE-01（2026-07-21ユーザー回答）により日本語版・英語版の両方を対象とすることが確定したため、英語版ページの閲覧は「通常」区分に含める。

## 5. カテゴリ別サマリー

| 区分 | カテゴリ | 件数 |
| --- | --- | --- |
| 通常 | ページ閲覧 | 8 |
| 通常 | お問い合わせ・応募 | 3 |
| 制約/例外 | フォーム入力の例外処理 | 2 |
| 自動/監査 | 自動処理・計測 | 3 |
| 未確定 | 運用者操作 | 1 |

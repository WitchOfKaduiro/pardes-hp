### 中文

Pardes Inc.（パルデス）は、自由意志を持つ汎用人工知能（AGI）の実現を目指すAIスタートアップです。

主力技術である「BiNet（バイネット）」は、誤差逆伝播法（バックプロパゲーション）を使用しない、生物学的妥当性の高いニューラルネットワーク技術です。神経伝達物質の働きを模した学習メカニズム、時間的な情報の蓄積・平滑化、確率的な収束による学習を組み合わせることで、従来の深層学習とは異なる知能原理の実装を目指しています。

今後は、BiNet SDK、BiNet Binary Module、Custom Integrationを通じて、ロボティクス系ベンチャー、研究機関、量産・実運用フェーズの企業に向けた提供を進めていきます。

### なにをやっているのか

```text
Pardes Inc.（パルデス）は、自由意志を持つ汎用人工知能（AGI）の実現を目指すAIスタートアップです。

私たちは、誤差逆伝播法（バックプロパゲーション）に依存しない、生物学的妥当性の高いニューラルネットワーク技術「BiNet（バイネット）」を研究開発しています。

BiNetは、神経伝達物質の働きを模した学習メカニズム、時間的な情報の蓄積・平滑化、確率的な収束による学習を組み合わせることで、従来の深層学習とは異なる知能原理の実装を目指す技術です。

今後は、BiNet SDK、BiNet Binary Module、Custom Integrationを通じて、ロボティクス系ベンチャー、研究機関、実運用フェーズの企業に向けた提供を進めていきます。
```

### なぜやるのか

```text
既存の深層学習は、大量の学習データ、GPUクラスタ、再学習・再デプロイを前提とすることが多く、ロボットやエッジデバイスのような物理世界の現場では導入が難しい場面があります。

Pardesは、この構造的な課題に対して、誤差逆伝播法に依存しない新しい知能原理の実装で挑んでいます。

あらゆる動体に「脳」を宿し、物理世界におけるAIの可能性を拡張すること。自由意志を持つ汎用人工知能（AGI）の実現へ近づくこと。それが私たちの挑戦です。
```

### どうやっているのか

```text
現在は少人数の研究開発チームで、BiNetのコア実装、独自OS研究開発、SDK・管理基盤、クラウド・アプリケーション領域の開発を進めています。

既にBiNet実装エンジニアが参画しており、初期メンバーとして技術選定、設計方針、実装方針に深く関われる環境です。

既存のAI開発の枠組みにとらわれず、C++、Python、Rust、CUDA、Linux、GPU環境などを活用しながら、AGI・ロボティクス・エッジAIに接続する基盤技術をつくっています。
```

### こんなことやります

```text
BiNetの研究開発と社会実装に向けたエンジニアリングを担当します。

主な業務内容:
- BiNetのコア実装
- CUDA C++、Rust等を用いた低レイヤー開発
- 独自OS研究開発
- BiNet SDK・管理基盤の開発
- クラウド・アプリケーション領域の開発
- ロボティクス・エッジAI領域への応用検証

必須スキル:
- C++ / Pythonの基礎知識
- RTX 40系GPU搭載PCでの開発環境

歓迎スキル:
- Linux環境での開発経験
- Gitを用いたチーム開発経験
- Rust / CUDA / 低レイヤー開発への関心
- 数学・物理学への強い興味
- AGI、ニューラルネットワーク、ロボティクスへの関心

まだ整っていないことも多い初期フェーズですが、その分、自分の実装がプロダクトと研究開発の方向性に直接反映されます。まずはカジュアルにお話ししましょう。
```

## AIO・SEO上の運用ポイント

- 外部媒体では、社名を `Pardes Inc.（パルデス）` に統一する。
- 製品名は初出で `BiNet（バイネット）` と表記し、以降は `BiNet` を使用する。
- `AGI`、`汎用人工知能`、`AI SDK`、`ニューラルネットワーク`、`ロボティクス`、`エッジAI` を不自然にならない範囲で本文に含める。
- 公式サイト、製品説明、採用情報へのリンクを設置する。
- 購入リンク、リンク集への大量登録、内容の薄い記事量産など、不自然な被リンク施策は行わない。
- 採用媒体、SNS、代表プロフィール、GitHub、技術ブログで表記を揃え、生成AIが同一企業・同一製品として認識しやすい状態にする。
